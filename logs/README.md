# Logs simulados

`auth.log` y `access.log` son **datos simulados** creados para el ejercicio (incidente
ficticio del 15-may 03:14). No proceden de ningún sistema real: las IP usan rangos de
documentación (RFC 5737) y el host y los usuarios son genéricos.

`analisis.sh` los correlaciona con grep/awk/join (Parte III de la memoria):

```bash
./logs/analisis.sh
```
